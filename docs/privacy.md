# Privacy and local data

Agent Usage uses the existing Codex CLI sign-in and reads account quota and token activity through the local Codex App Server process. It does not run an inference turn or request conversations. There is no Agent Usage account, hosted backend, analytics, or cloud sync in this version.

The app stores settings and account snapshots at `~/Library/Application Support/Agent Usage`. A snapshot can contain the account ID and email returned by Codex, plan type, quota percentages and reset times, token summaries and daily token counts, source status, and observation times. It separates snapshots by account and uses a hash of the account ID as the filename. The JSON contents are local files with user-only permissions; they are not encrypted. Settings include the last account ID, display choice, notification choice, and refresh interval. Alert deduplication keys are stored separately. The app does not copy Codex credentials, authentication tokens, or conversation content into its cache. CLI stderr is drained and discarded rather than logged.

Quota notifications are local and off by default. Launch at login is off by default and is registered with macOS only when enabled. Clearing cached usage in Settings removes saved account snapshots, but retains preferences and alert history. To remove all Agent Usage data, quit the app, turn off Launch at login if enabled, and delete `~/Library/Application Support/Agent Usage`; remove the app bundle separately. Codex CLI data remains under Codex's own home directory and is not removed by this app.
